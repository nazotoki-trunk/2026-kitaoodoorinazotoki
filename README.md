# 謎解きヒントサイト

謎解きイベント用の段階的ヒント公開サイトです。
スマホでの閲覧を想定したレスポンシブデザインになっています。

## ファイル構成

```
index.html          … ページ本体（編集不要）
css/style.css       … デザイン（編集不要）
js/app.js           … ページ生成スクリプト（編集不要）
js/hints-data.js    … ★文言データ（ここだけ編集する）
images/             … ヒントに画像を使う場合の置き場所
```

## 文言の差し替え方法

**編集するのは `js/hints-data.js` の1ファイルだけです。**

1. `js/hints-data.js` をテキストエディタで開く
2. `【 】` で囲まれたプレースホルダーを、制作チームから受け取った文言に置き換える
3. ブラウザで `index.html` を開いて表示を確認する

### よくある編集

| やりたいこと | 方法 |
| --- | --- |
| ヒントの数を増やす／減らす | `hints: [ ... ]` の配列に文字列を追加／削除 |
| 謎を増やす／減らす | `puzzles` 内の `{ ... }` ブロックをコピー／削除（`id` は重複しないように） |
| 章を増やす／減らす | `chapters` 内の `{ ... }` ブロックをコピー／削除 |
| 文中で改行する | 文字列の中に `\n` を書く |
| ヒントに画像を入れる | 画像を `images/` に置き、文字列の代わりに `{ text: "説明", image: "images/xxx.png" }` と書く |
| 解説を省略する | `answerNote: ""` のままにする（表示されません） |

## 動作の仕様

- ヒントはボタンをタップすると開閉します
- **答えは誤タップ防止のため2回タップで表示**されます（1回目で確認表示に変わる）
- 章が1つだけの場合、章タイトルは表示されず謎の一覧のみになります
- 検索エンジンに載らないよう `noindex` を指定済みです

## 公開方法

静的サイトなので、サーバーにフォルダごとアップロードするだけで動きます
（GitHub Pages / Netlify / レンタルサーバー等、どこでも可）。
ビルド作業は不要です。

## ローカルでの確認

`index.html` をダブルクリックしてブラウザで開くだけで確認できます。
