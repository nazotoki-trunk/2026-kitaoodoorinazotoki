# 北大通の巨大な影の謎を解け！ヒントページ

「北大通謎解きさんぽ2026」用の段階式ヒントサイトです。スマートフォンでの利用を前提に、各謎・ヒント・答えを入れ子のアコーディオンで表示します。

## ページ構成

| ページ | ファイル | 内容 |
| --- | --- | --- |
| 第一章 | `index.html` | かさ、気球、りんご、星1〜3、影の正体 |
| 第二章・最終章 | `chapter2.html` | 自転車、うさぎ、家、星1〜3、医者の正体、最終章 |

第一章から第二章・最終章へ、第二章・最終章から第一章へ相互に移動できます。イベントの最初のQRコードは `index.html` を参照してください。

## ファイル構成

```text
index.html             第一章
chapter2.html          第二章・最終章
css/style.css          見た目とレスポンシブ対応
js/app.js              ページ生成とアコーディオン制御
js/hints-data.js       ヒント、答え、画像パス
images/icons/          後から受け取るイラストの置き場所
images/README.md       イラストのファイル名一覧
tests/site-data.test.js データ整合性の確認
```

## イラストの追加方法

現在は、イラストが必要な場所にファイル名付きのプレースホルダーが表示されます。

受け取ったPNG画像を `images/icons/` に置き、[images/README.md](images/README.md) に記載されたファイル名へ変更してください。JavaScriptの編集は不要です。画像が存在すれば、プレースホルダーから自動で切り替わります。

例：かさのイラストを追加する場合

```text
images/icons/kasa.png
```

透過PNGを推奨します。表示時は縦横比を保ったまま枠内へ収まります。

## ヒント文の修正方法

文言、答え、章構成は `js/hints-data.js` に集約しています。

- `hints`: 上から「ヒント1」「ヒント2」…として表示
- `answer`: 2回押すと表示される答え
- `[[asset:compass]]` など: 本文中に画像またはプレースホルダーを挿入
- `assets`: イラストのファイルパス、代替テキスト、表示名

## ローカル確認

初回のみ依存関係をインストールします。

```sh
npm install
```

リポジトリ直下で次を実行し、表示されたURLをブラウザで開きます。

```sh
npm run dev
```

データ検査はNode.jsで実行できます。

```sh
npm test
```

公開用ファイルを `dist/` にまとめる場合は次を実行します。

```sh
npm run build
```

検索エンジンにヒントが掲載されないよう、両ページに `noindex, nofollow` を指定しています。
