# イラスト配置ガイド

受け取った画像を次のファイル名で `images/icons/` に配置してください。ファイルを置くと、ページ上のプレースホルダーが自動的に画像へ切り替わります。

| --- | --- |

| 気球 | `images/icons/kikyu.png` |
| りんご | `images/icons/ringo.png` |
| 自転車 | `images/icons/jitensha.png` |
| うさぎ | `images/icons/usagi.png` |

| サイコロ1 | `images/icons/dice-1.png` |

## 推奨形式

- PNG形式
- 背景透過
- 正方形に近い比率
- 1ファイルあたり500KB以下を目安

大きな画像も画面上では枠内へ縮小されますが、通信量を抑えるため事前の圧縮を推奨します。
